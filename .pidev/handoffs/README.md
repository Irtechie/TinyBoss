# PiDev Handoffs

Use this folder for compact restart packets.

A handoff should include:

- current branch;
- current working directory;
- touched files;
- test/build status;
- blockers;
- next command;
- rollback notes if execution changed files.

Keep durable state in repo files, not chat memory.

Template:

- `handoff-template.md`: compact restart packet for the next agent.
