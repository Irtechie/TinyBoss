# PiDev Plans

Use this folder for repo-local plans.

Every execution-ready plan should include:

- current branch;
- target files;
- expected changes;
- verification commands;
- rollback notes;
- handoff owner or next agent.

Do not ask an execution agent to run vague workstream bullets.

Templates:

- `kb-manifest-template.md`: multi-slice manifest for `kb-work` style execution.
- `slice-plan-template.md`: single vertical slice plan.
