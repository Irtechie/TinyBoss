# PiDev Repo Notes

This folder is repo-local. Keep app-specific memory, plans, handoffs, and operating notes here.

Do not put proprietary app details in global memory. Promote a repo-local lesson to global only when it applies to unrelated repos and can be written without repo names, secrets, private endpoints, customer data, or app-specific implementation detail.

Suggested folders:

- `memory/`: repo-specific facts and lessons.
- `plans/`: current and historical implementation plans.
- `handoffs/`: compact restart packets for future agents.
