# Repo-Local Memory

Use this folder for memory that belongs to this repo only.

Good entries:

- architecture notes;
- domain rules;
- project landmines;
- test/build/deploy commands;
- provider/model choices for this repo;
- model/eval results;
- project-specific user preferences.

Do not write secrets, credentials, tokens, customer data, or production data here.

Promotion test: if a lesson needs this repo's name to make sense, it stays repo-local.
