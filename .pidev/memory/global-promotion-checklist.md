# Global Promotion Checklist

Before promoting a repo-local lesson into global memory, all answers must be yes:

- [ ] Does it apply to multiple unrelated repos?
- [ ] Can it be written without repo names?
- [ ] Can it be written without proprietary architecture?
- [ ] Can it be written without secrets, credentials, endpoints, customer data, or production data?
- [ ] Would forgetting it create a repeat class of failure across repos?

If any answer is no, keep it repo-local.
